# NextStepUni character lab

Eight interactive concepts using the approved original mascot, personal Star Crew and subject artwork. Open `index.html` through the repository Vite server (currently port 3047).

## Public website

1. **Margin notes** — a responsive handwritten note alongside the existing hero, using the original mascot before account creation.
2. **Subject stories** — a fan of subject illustrations with useful descriptions and an accessible click/tap/keyboard selection.
3. **A warmer 404** — a branded missing-page illustration with clear recovery routes.

## Student app

4. **Your corner** — the selected personal character beside the existing home greeting; preserve the home layout.
5. **Study receipts** — a tangible visual record at the existing session-completion step.
6. **Little milestones** — an illustrated treatment for existing achievements; preserve current reward rules.
7. **Fresh pages** — helpful empty planner and saved-course states with a single next action.
8. **Off-duty mode** — an optional breathing rhythm and evening treatment during breaks.

Recommended first: Subject stories, Study receipts, Fresh pages.

The gallery is a local design preview. All student activity is illustrative. Shortlisting uses only the gallery's own `nsu-character-lab-shortlist` local-storage key. It does not modify app data. `artwork.js` is generated from the approved personal/subject artwork indexes; the preview uses the original assets without editing them.

Motion respects the system reduced-motion preference and can be reduced within the gallery. Examples support narrow screens and include a phone-width preview.
