# How They Did It — portraits

Drop a square PNG for each person here, named exactly `{portraitKey}.png`. The
deck loads `/assets/people/{portraitKey}.png` and falls back to the person's
initials if the file is missing, so you can add them one at a time.

Square images (e.g. 256×256 or 512×512), face centred. Keep file sizes small.
