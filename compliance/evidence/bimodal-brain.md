a default/background mode of brain function, mind-wandering aiding creative connection,
the incubation effect, and anticipatory aversion to starting hard tasks — each map to a
solid peer-reviewed source. Citations added; no content cut or reframed.

## Claim-by-claim record

- **§1 Two gears** — The "diffuse"/background mode corresponds to the brain's default
  mode of function active during rest and mind-wandering. **raichle2001.** The
  focused/diffuse labels are an explicit teaching metaphor, not a precise neuroanatomical
  claim. Verified.
- **§2–3 Focused vs Wandering** — Sustained focus can cause fixation; relaxed
  mind-wandering supports novel/creative connections ("Aha" moments). **baird2012**
  (mind wandering facilitates creative incubation). Verified. The pinball simulator is an
  illustrative metaphor.
- **§3–4 Switching / Incubation** — Stepping away from an unsolved problem lets it
  "incubate," improving later solution rates. **sio2009** (meta-analytic review of
  incubation). Verified. The Incubation Effect demo is an interactive illustration, not
  presented as study data.
- **§5 Why we put things off** — Anticipating an aversive/effortful task can register as
  genuine discomfort, prompting avoidance; committing to a tiny start defuses it.
  **lyons2012** (anticipation of an aversive task activates pain-related networks).
  Verified. (Procrastination is covered in depth in its own module.)
- **§6 Game plan** — Alternate genuine focused blocks with real (non-phone) breaks.
  Practical synthesis of the above.
