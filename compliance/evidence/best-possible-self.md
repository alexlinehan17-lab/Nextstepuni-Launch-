# Evidence Dossier — Best Possible Self

**Module:** `best-possible-self-protocol` (`components/BestPossibleSelfModule.tsx`)
**Review date:** 2026-06-23
**Reviewer:** Pre-accreditation literature review (DCU / Brian MacCraith)
**Governing rule:** Only state/advise what peer-reviewed literature supports; every DOI
verified via CrossRef. References surface via inline `Cite` markers + the module-wide
**References** button; data in `data/references/bestPossibleSelf.ts`.

**Reviewer note.** A clean motivation module built on Oettingen's research programme. Each
named element maps to a verified source: positive fantasising can sap energy/effort
(Kappes & Oettingen 2011), the "Best Possible Self" writing exercise (King 2001), mental
contrasting — expectations vs fantasies (Oettingen & Mayer 2002), and the if-then plan as
an implementation intention (Gollwitzer 1999). WOOP is the popular packaging of mental
contrasting + implementation intentions, both cited. **No content cut** — the module's
framing ("dream smarter", contrast dream with internal obstacles, pre-load a plan)
accurately reflects the literature. The WOOP Planner widget is a practical exercise, not a
data claim.

## Claim-by-claim record

- **§1 The Daydream Problem** — Positive fantasising about success, without contrasting
  reality, can drain the energy needed to act (**kappes2011**). Verified.
- **§2 The Best Possible Self Exercise** — Writing a vivid, detailed best-possible-future
  is a studied exercise with motivational/well-being benefits (**king2001**). Verified.
- **§3 The Reality Check** — Mental contrasting: pairing the imagined future with the
  internal obstacle generates the motivation to act (**oettingenMayer2002**). Verified.
- **§4 The WOOP Method** — Wish-Outcome-Obstacle-Plan; the Plan is an if-then
  implementation intention that pre-loads a response (**gollwitzer1999**). Verified.
- **§5 Build Your First WOOP** — Application exercise; no new empirical claim.
