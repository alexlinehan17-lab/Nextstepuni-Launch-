# Paper Trail answers — full correctness audit (2026-07-07)

Mandate: (1) verify every paper with the answers feature attaches the CORRECT
scheme regions; (2) re-assess every subject without the feature and implement
wherever honestly possible. Method: rebuild the scheme corpus from the app's
own Storage bucket (1,092 PDFs), structural + deployed-parity checks, a
full-corpus deterministic screen, then adversarial agent triage of every
flagged bucket AND a stratified sample of the passing bucket, with paper-side
cross-checks.

## Phase 1 — every existing map verified

**Inventory & parity.** 1,136 committed sidecars / 11,862 mapped questions.
Structural schema/band/rect scan: **0 issues**. All 1,121 index-flagged papers
have local sidecars, and all 1,121 sidecars are present in Storage (**0
missing**) — deployed parity is exact.

**Crop-text screen** (`verify_all.py`, whole corpus): OK 9,834 · MISMATCH
1,337 · NOMARK 581 · page-jump 82. Every flagged bucket was then triaged by
independent adversarial passes:

- **Language reading maps** (fr/de/es/it/ja/ru + LCA languages; 1,230 flags):
  **all correct-by-design** — sequential `n` + section-restart printed numbers
  carried in `label` (1,059 auto-cleared label-consistent; residue manually
  triaged; 18 questions cross-checked against the downloaded exam papers).
- **Wave-10 essays** (P&S, Classical; 75 flags): 73 correct-by-design common-
  block mappings; **2 real wrong-region defects, both in never-live sidecars —
  FIXED** (P&S 2018 HL Q2 → its Section B documents block; Classical 2023 OL
  Q11 → its own extended-answers block, Q10's over-run trimmed). Fixes
  verified by crop extraction.
- **Non-language tail** (45 flags, checked exhaustively): **0 real
  mis-anchors** — all false triggers of the marker heuristic (dimension
  values, equation soup, sub-part numbering, part labels). Computer Science's
  programming-paper Q1 (scheme Q16) gained an explanatory label. The ISL
  paper-side caveat was closed by direct paper↔scheme cross-check (content
  pairs exactly; running-index numbering).
- **Passing bucket** (40 stratified samples re-judged on content): 39 sound;
  **1 defect class — Home Ec Q5 over-inclusion** (Section C restarts numbering
  below 5, so the region never closed): systematic scan found 7 papers
  (2020–25), all **FIXED** (pure Section C pages dropped; trimmed crops
  verified). The Q5 answers themselves were always complete and correct.

**Phase-1 verdict: zero live wrong answers.** 2 wrong regions existed only in
dark (never-flagged) files; the one live defect class was cosmetic
over-inclusion. All 9 defective sidecars fixed and verified; 5 more gained
honest labels (CS ×2, ISL ×2, LCA Italian ×1).

**Tooling hardened:** `verify_all.py` is now label-aware (accepts the
section-restart design) — full-corpus mismatches drop 1,337 → 416, all within
the audited-correct residue, giving a tight regression baseline for future
waves.

**Also found: wave 10 was never switched on.** P&S + Classical sidecars were
generated, verified and 12/16 uploaded, but the index flags were never
rebuilt — the feature has been dark in production for both subjects, and 4
manifest rows (P&S HL 2018/2023/2025, OL 2021) never reached Storage. See
"Publish pass" below.
