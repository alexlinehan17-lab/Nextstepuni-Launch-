### Skills to Know About
- [/effort] — dials how hard Claude thinks, from quick answers to deep, careful work. The most-used command here; reach for it when a task needs real reasoning vs. a fast reply.
- [/compact] — summarises a long conversation so you don't run out of context mid-session. Used a lot here because sessions run long across big feature builds.
- [/btw] — drops in a quick aside or extra bit of context without derailing the task you're on.
- [/model] — switches the underlying Claude model when you want a different speed/capability trade-off.
